# 🛒 Mini Store

A simple e-commerce store built with HTML, CSS and JavaScript. Users can browse products, add them to a cart, change quantities and complete a demo checkout.

## 🔗 Live Demo
https://pawan-kumarsingh.github.io/mini-store/

## ✨ Features
- Product listing
- Add to cart and remove items
- Increase / decrease quantity
- Total price calculation
- Cart saved in browser (localStorage), so it stays after refresh
- Demo checkout form (no real payment)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run
1. Download or clone this repository
2. Open `index.html` in your browser

## 🚀 Future Improvements
- Add product images
- Add search bar and category filter
- Add login / register
- Connect backend using Node.js and MongoDB

## ⚠️ Note
This is a demo project. No real payment is processed. Please do not enter real card details.
